# License guide

This repository uses two licenses so learners can reuse both the teaching material and the working software.

## Software and interactive artifacts — MIT

The [MIT License](LICENSE) applies to application code, styles, build configuration, rendering components, and interactive artifact implementations. You may use, copy, modify, publish, distribute, sublicense, and sell the software, provided you keep the MIT copyright and permission notice.

## Educational content — CC BY 4.0

[CC BY 4.0](LICENSE-CONTENT.md) applies to original course prose, exercises, solutions, embedded diagrams, captions, and course-specific learning material. You may share and adapt it, including commercially, provided you give appropriate credit, link to the license, and indicate changes.

## When both apply

An interactive lesson often combines software with educational text. If you redistribute the whole artifact, preserve the MIT notice for its code and provide CC BY 4.0 attribution for its original learning content.

Dependency licenses remain their own. Run `npm install` and inspect the generated dependency license information when preparing a redistributed bundle.
