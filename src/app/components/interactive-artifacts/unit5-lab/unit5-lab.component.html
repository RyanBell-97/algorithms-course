What is random?

The adversary picks the keys first. Only afterwards does the table choose h uniformly from the family H. Because Pr[h(x) = h(y)] ≤ 1/m for every fixed pair, no input can be engineered to be slow — the guarantee is an expectation over h, not over the input.
